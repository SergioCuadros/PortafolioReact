# Portafolio Frontend Junior

Este es el portafolio personal de un desarrollador **Frontend Junior**. El proyecto está construido utilizando **Vite**, **Tailwind CSS** y **Framer Motion** para lograr una experiencia de usuario interactiva y rápida.

---

## 📥 Clonación e Instalación

Para comenzar con el proyecto en tu máquina local, sigue estos pasos:

### 1. Clonar el repositorio

Primero, clona este repositorio en tu máquina local:

```bash
git clone https://github.com/SergioCuadros/PortafolioReact.git
```

### 2. Instala las dependecias
```bash
npm install
```

### 3.Ejecutar el proyecto

```bash
npm run dev
```
## 🚀 Tecnologías Utilizadas
- Vite: Un entorno de desarrollo ultra-rápido para aplicaciones web.

- Tailwind CSS: Un framework de utilidades para diseñar interfaces de usuario de manera rápida y eficiente.

- Framer Motion: Una librería de animaciones para React, utilizada para agregar transiciones y efectos de movimiento a los componentes.

- React: Librería para construir interfaces de usuario interactivas.

## 🔧 Comandos Útiles
- npm run dev: Inicia el servidor de desarrollo y abre la aplicación en el navegador.

- npm run build: Construye la aplicación para producción.

- npm run preview: Previsualiza el proyecto de producción localmente después de construirlo.
